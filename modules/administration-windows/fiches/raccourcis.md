# Raccourcis Windows

_Source : Fiche raccourcis Windows administration réseau, p. 1–12. Synthèse personnelle ; commandes et pistes de mise en œuvre complémentaires, à vérifier._

## Les raccourcis essentiels
| Combinaison | Fonction |
|---|---|
| Win + R | Exécuter une console |
| Win + X | Menu système rapide |
| Win + E | Explorateur |
| Win + I | Paramètres |
| Win + L | Verrouiller |
| Ctrl + Maj + Échap | Gestionnaire des tâches |
| Alt + Tab | Changer de fenêtre |
| Win + Maj + S | Capture d'une zone |
| Win + V | Historique presse-papiers |
| Win + Tab | Vue des tâches |
| Win + Ctrl + D | Créer un bureau virtuel |
| Win + Ctrl + gauche/droite | Changer de bureau |
| Win + Ctrl + F4 | Fermer le bureau virtuel |
| Win + flèches | Ancrer les fenêtres |
| Ctrl + Maj + N | Nouveau dossier |
| F2 / F5 | Renommer / actualiser |
| Alt + D | Barre d'adresse (chemin UNC) |
| Alt + Entrée | Propriétés |
| Maj + F10 | Menu contextuel |
| Tab / Maj + Tab | Changer de champ |

## RDP et Server Manager
| Raccourci | Action |
|---|---|
| Ctrl + Alt + End | Ctrl+Alt+Suppr sur le serveur distant |
| Ctrl + Alt + Break | Basculer plein écran distant |
| Alt + Page Up/Down | Changer de programme distant |
| Alt + M / V / H | Manage / View / Help dans Server Manager |
| Alt + P / R / T | Propriétés locales / services ou gestion distante selon vue / NIC Teaming selon vue |
| F5 | Actualiser |
Certains raccourcis varient selon la version, la langue, la vue et les réglages de la session distante.
