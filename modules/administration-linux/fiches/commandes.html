Commandes Linux essentielles

Commandes courantes, notes de lab et points de vigilance.

Système et services

Vérifier l'état de la machine et des unités systemd.

Shell · Oracle Linux 8 
cat /etc/os-release
uname -r
hostnamectl
systemctl status sshd
systemctl get-default

Réseau

Inspecter interfaces, routage et résolution.

Shell · Oracle Linux 8 
ip a
ip r
nmcli connection show
cat /etc/resolv.conf

Paquets

Gérer les RPM et leurs mises à jour.

Shell · Oracle Linux 8 
dnf repolist
dnf provides '*/day.jpg'
dnf check-update
dnf history info last

Stockage et fichiers

Comprendre les disques et l'utilisation des volumes.

Shell · Oracle Linux 8 
lsblk -f
blkid
findmnt
df -hT
du -sh /var

Comptes et permissions

Contrôler identité, groupes et droits.

Shell · Oracle Linux 8 
id
getent passwd
getent group
ls -l
stat /etc/passwd
umask

Journalisation

Chercher la cause d'un incident.

Shell · Oracle Linux 8 
journalctl -b
journalctl -u sshd
journalctl -p err -b
free -h
top
