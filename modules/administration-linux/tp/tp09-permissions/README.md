# Atelier 9 — Gestion des permissions

Droits classiques et spéciaux

**Guide personnel, non corrigé officiel.**

## Déroulement
1. Vérifier les droits initiaux sur les fichiers de test.
2. Changer les droits avec chmod et chown.
3. Tester les accès avec les identités prévues par le TP.

## Commandes utiles
```bash
ls -l
stat fichier
chmod --help
umask
```

Captures du avant/après et tests d'accès autorisés/refusés.
