# Atelier 1 — Installation graphique

Installer Oracle Linux avec interface graphique

**Guide personnel, non corrigé officiel.**

## Déroulement
1. Créer une VM graphique et sélectionner le média d'installation.
2. Préparer l'utilisateur, les partitions et le réseau.
3. Vérifier la connexion et l'identité de la distribution.

## Commandes utiles
```bash
cat /etc/os-release
lsblk -f
systemctl get-default
```

## À prouver
Captures de l'installation, du partitionnement et de la première connexion.
