# Atelier 5 — Configuration réseau

NetworkManager, IP, DNS et routage

**Guide personnel, non corrigé officiel.**

## Déroulement
1. Afficher IP, route et DNS avant tout changement.
2. Configurer la connexion via nmtui ou nmcli.
3. Vérifier la connectivité et documenter le résultat.

## Commandes utiles
```bash
ip a
ip r
cat /etc/resolv.conf
nmtui
nmcli connection show
```
