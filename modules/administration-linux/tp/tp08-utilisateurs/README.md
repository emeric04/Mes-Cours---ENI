# Atelier 8 — Utilisateurs et groupes

Comptes locaux, GID/UID et appartenances

**Guide personnel, non corrigé officiel.**

## Déroulement
1. Observer les comptes et groupes existants.
2. Créer les comptes et groupes explicitement demandés.
3. Vérifier les appartenances et les possibilités de connexion.

## Commandes utiles
```bash
getent passwd
getent group
id
useradd --help
usermod --help
```

## À prouver
Afficher id/getent et les résultats des commandes sans publier de secrets.
