# Atelier 11 — Informations système et processus

Diagnostic CPU, RAM, disques et processus

**Guide personnel, non corrigé officiel.**

## Déroulement
1. Relever la version système, le noyau et l'architecture.
2. Observer l'utilisation CPU/RAM et les processus.
3. Comparer les résultats et rédiger un court diagnostic.

## Commandes utiles
```bash
cat /etc/os-release
uname -a
lscpu
top
free -h
ps -ef
```

Captures des commandes et commentaires sur les ressources observées.
