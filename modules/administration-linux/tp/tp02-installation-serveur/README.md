# Atelier 2 — Installation serveur

Installer Oracle Linux sans interface graphique

**Guide personnel, non corrigé officiel.**

## Déroulement
1. Créer une seconde VM dédiée au mode console.
2. Comparer les ressources et les services entre serveur et client.
3. Vérifier l'accès console et le réseau.

## Commandes utiles
```bash
systemctl get-default
ip a
df -hT
```

## À prouver
Capture de la connexion console et de la configuration de base.
